TableTidy

A CSV and Excel editor for Mac that opens files without broken characters, lost zeros or merged columns.

Help

  • Strange characters after opening? Choose another character set in the import options (File → Change Import Options). Files from Windows in Russian are usually Windows-1251; Western European files are usually Windows-1252.
  • Everything is in one column? Tick the separator the file uses: semicolon, tab, comma or another character.
  • Excel shows broken characters in a saved file? Save As → preset “Excel (Windows)”: UTF-8 with a byte order mark.
  • “Can't be saved in …” The chosen character set has no such character. TableTidy names the row and column; choose UTF-8 or change the cell.
  • Excel files with several sheets: open the .xlsx file; each sheet gets a tab at the bottom. Saving as CSV keeps only the current sheet; File → Save As → Excel workbook keeps all of them (Pro).
  • Comparing two lists: put both in one file as sheets (the + button at the bottom, or Insert → Sheet from Another File), then Data → Compare Sheets. Match rows by a key column such as an article number, choose the columns to compare, and see added, missing and changed rows highlighted. A Differences sheet lists every change.
  • Find: ⌘F opens the find bar above the table; ⌘G and ⇧⌘G go to the next and previous match.
  • Restore TableTidy Pro on another Mac: TableTidy → Settings → Restore Purchase.
