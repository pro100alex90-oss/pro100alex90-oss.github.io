TableTidy

A CSV editor for Mac that opens files without broken characters, lost zeros or merged columns.

Help

  • Strange characters after opening? Choose another character set in the import options (File → Change Import Options). Files from Windows in Russian are usually Windows-1251; Western European files are usually Windows-1252.
  • Everything is in one column? Tick the separator the file uses: semicolon, tab, comma or another character.
  • Excel shows broken characters in a saved file? Save As → preset “Excel (Windows)”: UTF-8 with a byte order mark.
  • “Can't be saved in …” The chosen character set has no such character. TableTidy names the row and column; choose UTF-8 or change the cell.
  • Restore TableTidy Pro on another Mac: TableTidy → Settings → Restore Purchase.
